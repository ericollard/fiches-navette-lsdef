Générateur de fiches navette UE

Licence Sciences de l'éducation et de la formation, nouvelle offre de formation 2027.

1Choisir le classeur de base

Le classeur reste sur votre ordinateur. Il n'est ni transmis, ni enregistré sur le serveur : la page produit les fiches dans votre navigateur, hors ligne si besoin.

Déposez ici le classeur de base ou cliquez pour le choisir. Fichier .xlsx, son nom n'a pas d'importance.

2Vérifier ce que contient la base

Ces nombres sont lus dans le classeur que vous venez de choisir. Ils vous permettent de vérifier que c'est bien la version attendue avant de produire les fiches.

3Produire les fiches

Le modèle de fiche est fourni avec la page. Si votre comité en adopte une nouvelle version, vous pouvez la substituer ci-dessous.

    ?En cas de difficulté

    Si un message d'erreur nomme une clé de texte ou une feuille, la correction se fait dans le classeur et non dans la page : rien de ce qui s'écrit dans les fiches ne figure dans le programme. Les phrases fixes sont dans la feuille Ref_Textes, la correspondance des régimes d'évaluation dans Ref_Gabarit_fiche.

    Traitement entièrement local. Aucune donnée ne quitte votre navigateur.
